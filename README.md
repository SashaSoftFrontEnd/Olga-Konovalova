# Olga Konovalova - Professional Website

A modern, responsive portfolio website for Olga Konovalova, a Marketing and PR expert with extensive experience in corporate environments. The website is built using React and Vite, and implements B.J. Fogg's Behavior Model principles to optimize user engagement and conversion.

## Features

### B.J. Fogg's Behavior Model Implementation

The website is designed following B.J. Fogg's Behavior Model, which focuses on three core elements:

#### 1. **Motivation** (Мотивация)
- Success metrics display (15+ years experience, 50+ successful projects, 100% client loyalty)
- Achievement highlights and recognition
- Clear value proposition
- Social proof through recommendations

#### 2. **Ability** (Способность)
- Smooth scrolling navigation
- Prominent and accessible contact buttons
- Clickable project and service cards
- Back-to-top button for easy navigation
- Clickable phone and email links
- Mobile-responsive design

#### 3. **Prompts** (Триггеры)
- Floating contact button (always visible with pulse animation)
- Multiple CTAs throughout the page
- Scroll-triggered fade-in animations
- Micro-interactions and hover effects
- Clear call-to-action text in footer
- Visual hints on cards ("Click to discuss", "Learn more →")

## Technologies Used

- **React 18.3.1** - Modern UI library
- **Vite 6.0.5** - Fast build tool and dev server
- **React Icons** - Icon library
- **CSS3** - Custom styling with animations and gradients

## Installation

```bash
# Clone the repository
git clone https://github.com/visualGravitySense/olga-konovalova.git

# Navigate to the project directory
cd olga-konovalova

# Install dependencies
npm install
```

## Development

```bash
# Start development server
npm run dev

# The site will be available at http://localhost:5173
```

## Build

```bash
# Build for production
npm run build

# Preview production build
npm run preview
```

## Deployment

The website is deployed to GitHub Pages. To deploy updates:

```bash
# Build and deploy to GitHub Pages
npm run deploy
```

The site will be available at: `https://visualGravitySense.github.io/olga-konovalova/`
